# Новострой37 — сайт салона плитки

Одностраничный адаптивный сайт. Стек: Python Flask, Jinja HTML templates, CSS и небольшой vanilla JavaScript для фильтрации каталога и мобильного меню.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте `http://127.0.0.1:5000`.

Форма показывает подтверждение заявки, но не сохраняет и не отправляет персональные данные. Перед публикацией замените контакты и реквизиты на проверенные, добавьте настоящую политику конфиденциальности и подключите обработчик заявок.
